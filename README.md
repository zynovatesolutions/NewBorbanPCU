# GoldenPlus - Business Management System

GoldenPlus is a comprehensive business management system designed to streamline operations for businesses dealing with inventory, sales, and customer management. The application is built using React and Redux, providing a modern and efficient user interface.

## 🚀 Features

### Admin Module

- **Invoices Management**

  - Customer Invoices
  - Supplier Invoices
  - Invoice Creation and Editing
  - Invoice Printing
  - Return Invoices

- **Inventory Management**

  - Stock Management
  - Item Management
  - Stock Tracking
  - Inventory Reports

- **Customer Management**

  - Customer Profiles
  - Customer Ledger
  - Customer Transactions
  - Payment History

- **Supplier Management**

  - Supplier Profiles
  - Supplier Ledger
  - Purchase Orders
  - Payment Tracking

- **Financial Management**
  - Expense Tracking
  - Payment Processing
  - Account Management
  - Financial Reports

### Manager Module

- Sales Management
- Inventory Control
- Customer Service
- Basic Reporting

### Authentication

- Secure Login
- Role-based Access Control
- User Management

## 🛠️ Technical Stack

- **Frontend Framework**: React.js
- **State Management**: Redux
- **Routing**: React Router
- **UI Components**: Custom Components
- **Styling**: Tailwind CSS
- **API Integration**: Axios

## 📁 Project Structure

```
src/
├── assets/          # Static assets and configurations
├── components/      # Reusable UI components
├── pages/          # Page components
│   ├── Admin/      # Admin module pages
│   ├── Manager/    # Manager module pages
│   └── Auth/       # Authentication pages
├── store/          # Redux store configuration
├── utils/          # Utility functions
└── ApiRequests/    # API integration
```
